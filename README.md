# K.O. II in the browser

A browser-based recreation of the Teenage Engineering EP-133 K.O. II sampler, built with the Web Audio API.

Open `ko2.html` in a modern browser (Chrome or Safari) to play. It's a single self-contained file; the source modules it's built from live in `src/`.

Features: pressure/velocity-sensitive pads (Force Touch, pen pressure, click position, MIDI), scenes and song mode, 12 punch-in FX, time-stretch, fader automation, sampling and resampling, velocity layers, step lock, and WAV export with FX.
